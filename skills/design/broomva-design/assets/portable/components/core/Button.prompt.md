Pill-shaped action button. Use primary ink fill for the one main action and secondary, soft, or ghost variants for supporting actions.

```jsx
<Button variant="primary">Add to cart</Button>
<Button variant="secondary">Connect</Button>
<Button variant="ghost" size="sm">Cancel</Button>
```

Variants: primary | secondary | soft | ghost. Sizes: sm (28) | md (36) | lg (44). Labels are sentence case and lead with the verb.
