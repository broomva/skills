# Example world: Lantern Market

A small, **fictional** world built to show the output contract filled in. Its owner,
"the example owner", is invented, and so are their taste, answers and references. It passes
`python3 ../../scripts/world_check.py check . --complete`, and the tests mutate copies of it
to prove each check can fail.

It is deliberately small: two characters, one location, one prop, one account. A real world
has more of each and many more rounds.
