# Field notes

One folder per target (`<target>/<slug>.md`), in the format of `../references/field-note.md`,
linted by `../scripts/modlog.py lint-note`. Each note records what one real run learned:
versions, route, what the target really does, evidence, and gotchas.

Search here before starting a run on a target. Add your note when the run ends, whether the
mod worked or not.
